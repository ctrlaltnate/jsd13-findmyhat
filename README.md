# การออกแบบ Game Find Your Hat
## การออกแบบแผนที่และเกมเพลย์
1. Map ตาราง 2 มิติ Array ($X * Y$)
   - แทนพื้นที่ในเกมกำหนดสัญลักษณ์ชัดเจน เช่น ░ (พื้นที่ว่าง), O (หลุม), ^ (หมวก), * (ตัวผู้เล่น) 
2. Player Position
   - ตัวแปรเก็บพิกัดปัจจุบันของผู้เล่น เช่น (row, col) หรือ (y, x)
3. Game Status
   - ตัวแปรบอกสถานะว่าเกมกำลังเล่นอยู่ หรือจบแล้ว (isPlaying = true/false)

## การสุ่มพิกัดของ หลุม หมวก และตัวผู้เล่น 
จุดนี้ต้องวางเงื่อนไขเพื่อไม่ให้เกมค้างหรือสุ่มแล้วเล่นไม่ได้

    - สุ่มวาง Actor (ตัวผู้เล่น): สุ่มพิกัดเริ่มต้น (นิยมเป็น (0, 0))
    - สุ่มวาง Hat (เป้าหมาย): สุ่มพิกัด (row, col) ห้ามทับ ตำแหน่งผู้เล่น
    - สุ่มวาง Holes (หลุม):

** กำหนดเปอร์เซ็นต์ความยาก (เช่น 20% ของพื้นที่ทั้งหมด)
** วนลูปสุ่มใส่หลุม โดย ห้ามทับ ทั้งตัวผู้เล่นและหมวก

## ออกแบบ col
กำหนดหน้าที่ของ Class ตามที่เกณฑ์ต้องการ 
constructor() รับค่าแผนที่ หรือสั่งสร้างแผนที่สุ่ม พร้อมตั้งค่าตำแหน่งผู้เล่นเริ่มต้น
print() วนลูปแสดงผลแผนที่ลงบน Console ให้ผู้เล่นเห็นปัจจุบัน
moveRight(), moveLeft(), moveUp(), moveDown():
quit() ไว้ออก 

โดยแต่ละ move มี หน้าที่คือเปลี่ยนพิกัด (row, col) ของผู้เล่นไปในทิศทางนั้นๆ เช่น ขึ้นคือ row - 1, ลงคือ row + 1
โดยทุกครั้งที่เดินซ้ายหรือขวาบนล่าง ต้องเช็คตัวละครเสมอว่า 
 1. ตกขอบไหม
 2. เจอหมวกไหม
 3. เจอหลุมไหม 

# Flow การทำงานเกม
รับ Input จากผู้เล่น: วนลูปถามคำสั่ง (L/R/U/D) 

1. อัปเดตพิกัดด้วย เรียกใช้ Method move...() ตามคำสั่งที่รับมา
2. ตรวจสอบเงื่อนไขการจบเกม 
    - 🚫 Out of bounds พิกัดใหม่ < 0 หรือมากกว่าขนาดแถว/คอลัมน์หรือไม่? ถ้าใช่ แสดงข้อความแพ้และจบเกม 
    - 💀 Fell into a hole พิกัดใหม่เจอป้าย O หรือไม่ ถ้าใช่ แสดงข้อความแพ้และจบเกม
    - 🎉 Found the hat พิกัดใหม่เจอป้าย ^ หรือไม่? ถา้เจอแสดงข้อความชนะ แลัจบเกม
    - Update & Print Map ถ้ายังไม่แพ้/ชนะ ให้ย้ายสัญลักษณ์ * ไปที่พิกัดใหม่เคลียร์หน้าจอแล้วสั่ง - print() แผนที่ใหม่อีกครั้ง แล้ววนกลับไปรับ Input ใหม่



** ข้อควรระวัง บางครั้ง ต้องกำหนด พื้นที่ ให้ สัมพันธ์กับ เปอร์เซนต์ของหลุมด้วย โดย default= 20% ของพื้นที่ ที่เดินได้จริง และไม่ถูกบล็อก (เดินไปยังไงก็เจอหลุม ตกขอบ โดนล้อม)
